# Task Completion Checklist

## Before Finishing Any Task
1. Run tests: `uv run pytest`
2. Check code formatting (if configured)
3. Verify existing functionality unchanged
4. Test new functionality manually if applicable
5. Update documentation if needed

## Code Quality Standards
- Follow existing naming conventions
- Add type hints for new functions
- Include docstrings for new classes/functions
- Maintain Player 1 perspective consistency
- Use existing utility functions when possible

## Testing Requirements
- Unit tests for new game logic
- Integration tests for new features
- Verify no regression in existing tests
- Test edge cases and error conditions
